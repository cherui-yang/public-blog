# 三下乡农产品宣传方式整合

## 一、直播带货类

### 1. 果园实景直播

湖南科技学院实践团创新多场景联动直播助农模式，队员走进田间地头实拍西瓜、香米、酥脆枣、高山干笋等特色作物原生态生长环境，构建田间实景、圩市外景、古院专场三线联动直播体系。

安徽砀山李庄镇，大学生依托“和美乡村直播间”平台，开启“田间实景+室内直播间”双模式直播，一边展示刚刚采摘的早熟梨、亲手制作的黄桃罐头，一边讲述走村入户的所见所闻。

### 2. 非遗文化+直播

南通大学调研团在白蒲镇助农直播间，依托本土电商平台“蒲涛优选”，以实景展示、口感分享、工艺讲解的形式推介白蒲茶干、林梓潮糕等非遗美食。直播间工作人员介绍，以前非遗特产大多线下售卖、销路受限，现在通过常态化助农直播，优质生态农产品走出乡镇、销往全国。

### 3. 持续化直播助农

广西科师学子连续三年扎根乡村开展直播助农服务，开播不到两小时销售额达2700元，直播间点赞互动接近1万人次。

## 二、短视频与新媒体内容类

### 1. 短视频推广农产品

2018年火山小视频与安徽黟县合作，推出“火山三农合伙人”计划，成立国内首家乡村短视频工作站，用短视频推广当地农产品。黟县当地农产品长期只藏在深山里，通过短视频和直播的传播新形式，走出了宣传推广的第一步。

### 2. 沉浸式体验记录

有团队尝试“沉浸式体验”，和村民同吃同住同劳动，用短视频记录“大学生变身新农人”的全过程，这样的内容天然具有传播力。
