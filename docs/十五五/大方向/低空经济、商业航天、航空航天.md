# 低空经济 + 商业航天：产业链、专业与岗位全景拆解

> **低空经济 + 商业航天 = 空天产业**。航空航天被写入了政府工作报告，被定义为“新兴支柱产业”。**低空经济**是在距地面3000米以下的空域，用无人机、eVTOL（电动垂直起降飞行器，俗称“空中出租车”）等飞行器做物流、载人、巡检等场景的经济活动。**商业航天**则是把造火箭、发卫星、卫星联网这些过去由国家干的事情，开放给民营企业来做，形成市场化产业链。**两个产业共享底层技术**——材料、动力、控制、通信、导航定位，底层完全相通。

**市场体量**：低空经济2025年市场规模预计突破1.5万亿元，到2035年有望达3.5万亿元；商业航天2025年全产业链市场规模预计突破2.5万亿元。


## 一、低空经济产业链

低空经济产业链分为**上游、中游、下游、支撑体系**四大类，细分为18个子类，涵盖从原材料到应用服务的全链条。

### （一）上游：原材料、零部件与研发

**干什么的**：造飞行器需要的“原料+零件+大脑”，决定飞行器能不能飞起来、飞得好不好。

**生态位**：
- **金属材料与复合材料**：造机身骨架、机翼等，代表企业包括航材股份、航玻新材等，主要提供铝合金、碳纤维、钛合金等轻量化材料。
- **动力电池**：eVTOL和大型无人机的“心脏”，核心企业有宁德时代、欣旺达、中创新航。
- **飞控与导航系统**：飞行器的“大脑+小脑”，负责飞行姿态控制和路线规划。代表企业有边界智控（飞控+导航）、丰飞智控。
- **感知与芯片**：飞行器的“眼睛+耳朵”，包括毫米波雷达芯片、视觉芯片、定位感知模组。代表企业有导远科技、肇观电子等。
- **核心设备与系统**：包括航电系统、通信链路等，代表企业有航新科技、安达维尔等。
- **研发创新与仿真设计**：为飞行器提供概念设计、气动仿真、结构优化等技术服务。

**适配的专业**（[专业名]格式）：

1. [材料科学与工程](材料科学与工程.md)——搞轻量化机身材料（碳纤维、钛合金、航空铝合金）的研发与检测。
2. [新能源科学与工程](新能源科学与工程.md)——研发高能量密度电池，解决eVTOL和无人机的续航难题。
3. [电子信息工程](电子信息工程.md)——设计飞控系统、航电设备、通信链路。
4. [自动化](自动化.md)——开发飞行控制算法、导航与控制一体化系统。
5. [电气工程及其自动化](电气工程及其自动化.md)——研发电机、电驱系统，搞定飞行器的动力电控。
6. [测绘工程](测绘工程.md)——参与无人机航测的传感器选型与数据采集方案设计。

### （二）中游：航空器制造、飞行保障与综合服务

**干什么的**：把上游的零部件组装成完整的飞行器，再建好地面基础设施，让飞行器能上天、能落地。

**生态位**：
- **航空器整机制造**：分为eVTOL整机、无人机、通航飞机三条细分赛道。eVTOL代表企业有小鹏汇天、亿航智能、沃兰特航空、峰飞航空等；无人机代表企业有大疆创新、纵横股份、极飞科技等。
- **地面配套装备**：包括起降设施、充电换电设备、维修保障装备等。
- **飞行保障**：包括空域管理、通信导航监视（CNS）、低空飞行管理或服务系统（UTM/USSP/UAM云平台等）、安全防控等。
- **综合服务**：包括保险、适航检测认证、飞行培训、维修维护等。

**适配的专业**：

1. [飞行器设计与工程](飞行器设计与工程.md)——整机总体设计、气动布局、结构设计。
2. [飞行器动力工程](飞行器动力工程.md)——研发航空发动机、电推进系统、旋翼系统等动力装置。
3. [无人驾驶航空器系统工程](无人驾驶航空器系统工程.md)——无人机和eVTOL的系统集成、测试验证和运维管理。
4. [航空航天工程](航空航天工程.md)——飞行器多学科综合设计（结构、动力、控制、热管理一体化）。
5. [计算机科学与技术](计算机科学与技术.md)——开发空管系统、低空飞行管理平台、机载软件和仿真系统。
6. [通信工程](通信工程.md)——建设低空通信网络（5G-A通感一体化等），保障飞行器与控制中心实时通信。

### （三）下游：运营服务与产业应用

**干什么的**：把造好的飞行器真正跑起来、用起来，送到用户手里。

**生态位**：
- **低空物流配送**：用无人机送快递、外卖、医疗物资。代表企业有顺丰（丰翼科技）、美团、京东等。
- **低空出行（城市空中交通UAM）** ：用eVTOL做空中出租车，代表企业有沃飞长空、亿航智能等。
- **低空文旅与消费**：飞行观光、航拍、编队表演、飞行体验等。亿航的EH216-S已获得全球首个载人无人驾驶eVTOL的型号合格证（TC）、生产许可证（PC）和标准适航证（AC）。
- **工业应用**：农林植保（极飞科技）、电力巡检（科比特航空）、地理测绘（纵横股份）等。
- **应急救援与公共服务**：消防灭火、灾情侦查、医疗物资紧急配送等。

**适配的专业**：

1. [物流管理与工程](物流管理与工程.md)——设计无人机物流网络、优化配送路径。
2. [交通运输](交通运输.md)——规划城市空中交通（UAM）航线网络与起降场布局。
3. [地理信息科学](地理信息科学.md)——无人机遥感数据采集、处理与行业应用分析。
4. [工商管理](工商管理.md)——低空经济场景商业化、企业运营管理与市场拓展。
5. [旅游管理](旅游管理.md)——低空文旅项目策划、飞行体验产品的商业化运营。
6. [应急管理](应急管理.md)——将无人机应用到应急救援场景（灾情监测、物资投送、灾后评估）。

## 二、商业航天产业链

商业航天产业链分为**上游制造、中游发射与运营、下游应用**三大环节。可类比为“淘金产业生态”：上游“卖铲子”，中游“送淘金客上路”，下游“把金子变成商品”。

### （一）上游：火箭/卫星制造及配套

**干什么的**：造火箭、造卫星，以及所有配套的核心零部件和材料。

**生态位**：
- **火箭制造**：包括火箭结构/骨架（特种材料、3D打印零部件）、火箭发动机（液体火箭发动机、固体火箭发动机）、航电与控制系统等。代表企业有蓝箭航天（液氧甲烷火箭）、星河动力（固体火箭）、中科宇航（亚轨道飞行器）等。
- **卫星制造**：包括卫星平台（结构、热控、电源、姿控等）和有效载荷（通信转发器、遥感相机、导航载荷等）。代表企业有中国卫星（小卫星批产）、银河航天（通信星座）、长光卫星（遥感星座）、微纳星空（微小卫星平台）。
- **关键配套**：特种气体/液氢燃料（如九丰能源）、高端轴承（如国机精工）、3D打印零件（如铂力特）、星载芯片（如铖昌科技）、航天电子系统（如航天电子）等。
- **地面设备制造**：包括卫星测控站、信关站、移动终端天线等。

**适配的专业**：

1. [飞行器设计与工程](飞行器设计与工程.md)——火箭总体设计、弹道规划，或卫星总体设计、结构力学分析。
2. [飞行器动力工程](飞行器动力工程.md)——液体/固体火箭发动机设计与测试、推进剂研发。
3. [航空航天工程](航空航天工程.md)——航天器多学科综合设计与集成，系统工程方法论。
4. [机械工程](机械工程.md)——火箭/卫星精密机械结构设计、3D打印制造工艺。
5. [电子信息工程](电子信息工程.md)——星载电子系统（测控、通信、计算机）设计与集成。
6. [材料科学与工程](材料科学与工程.md)——航天级特种材料（耐高温、抗辐射、轻量化复合材料）研发。

### （二）中游：火箭发射服务与卫星运营

**干什么的**：把卫星送上天（发射服务），再在天上进行日常管理和数据中继（卫星测控运营）。

**生态位**：
- **火箭发射服务**：包括一次性发射和可回收发射，提供“一箭多星”服务。代表企业有航天科工火箭技术公司（快舟系列）、星河动力（谷神星系列）、星际荣耀（双曲线系列）、中科宇航等。
- **卫星测控与运营**：卫星上天后的“管家”，负责卫星的跟踪、遥测、指令控制和状态监测，维持卫星正常运行。
- **发射场/发射工位**：提供发射场地保障、燃料加注等服务。目前全国商业航天发射工位合计25个（在运营18个、在建7个）。
- **频率/轨位资源申请管理**：卫星频率和轨道位置的国际协调与申请。

**适配的专业**：

1. [航空航天工程](航空航天工程.md)——火箭发射总体方案设计、测控方案制定。
2. [计算机科学与技术](计算机科学与技术.md)——开发卫星测控软件、发射指挥控制系统。

## 三、低空经济 × 商业航天：融合交汇点

低空经济与商业航天并非两个孤立的赛道，它们在产业链多个环节存在深度交叉与协同：

### 1. 技术共享层
航空航天被统筹纳入同一个产业范畴，二者在材料、动力、控制、通信、导航定位等底层技术上具备高度相通性。造eVTOL的复合材料、飞控芯片，和造卫星的结构件、星载计算机有大量的技术复用空间。

### 2. 空域与基础设施协同
低空经济需要低空的通信、导航、监视基础设施，而商业航天的卫星互联网可以为低空飞行器提供全球覆盖的通信与高精度导航增强服务。北斗+低轨星座=为低空飞行器提供厘米级定位。

### 3. 数据融合应用
卫星遥感数据+无人机近地采集数据=“天上看+地上巡”的立体化监测体系，在农业、环保、应急等领域具有巨大协同价值。

### 4. 人才需求共性
两个产业都需要大量“交叉复合型”人才——既要懂航空航天硬技术，又要懂AI算法、通信网络、商业运营。低空经济领域复合型人才占比需求高达60%以上。商业航天同样不仅需要专业技术人才，更需要懂市场、懂行业、懂应用的复合型人才。


## 四、全局视角：为什么要把这两个产业合起来看？

1. **共享底层技术**：航空与航天在材料科学、空气动力学、推进技术、控制理论、通信导航等基础学科上高度共通。造火箭发动机的技术能力和造eVTOL电推进系统的工程能力在方法论上是相通的。
2. **政策顶层定位一致**：航空航天被整体定位为“新兴支柱产业”，低空经济也被明确纳入战略性新兴产业集群，二者在同一政策框架下协同发展。
3. **产业链互补**：商业航天的卫星互联网能为低空经济提供通信+导航基础设施；低空经济的无人机产业链则为小型化、低成本航天器提供了供应链基础。
4. **人才流动空间广阔**：在空天产业的大框架下，专业人才在两个领域的迁移成本极低，职业发展空间成倍放大。
5. **应用场景融合加速**：卫星遥感+低空无人机巡检、卫星通信+低空飞行器远程控制、太空算力+低空海量数据处理，融合创新空间正在打开。
